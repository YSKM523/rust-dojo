## Design Context

### Users
Rust Dojo is being shaped as a public product showcase for people evaluating the project at first glance. The primary visitor is not only a learner, but also a reviewer, recruiter, peer developer, or potential user who needs to quickly understand that this is a polished Rust backend training product with real practice depth.

### Brand Personality
Professional, modern, high-impact. The product should feel like a premium technical learning product: precise enough for engineers, editorial enough for public presentation, and energetic enough to make the first viewport memorable.

### Aesthetic Direction
Use an Awwwards-inspired product-site direction, not a generic SaaS dashboard. The homepage should carry a strong brand moment with a dark code/data stage, dense metadata, crisp typography, precise orange accents, and restrained motion. Tool pages should preserve clarity and speed while borrowing the same premium visual language.

### Design Principles
- Make the first viewport unmistakably product-grade: brand, value, code, and data depth must be visible immediately.
- Use dark technical surfaces for code/workbench moments and lighter editorial surfaces for learning/resource content.
- Prefer compact metadata, dividers, and rhythm over large empty cards.
- Keep real actions prominent: start a lesson, open resources, follow the route, and compile Rust.
- Motion should clarify hierarchy through fast reveals and hover feedback, while respecting reduced-motion preferences.
