Why Rust / 岗位事实

为什么是 Rust

下面四条都来自 2026-07 Indeed 加拿大 / 美国岗位与公开招聘页的调研，不是感想。路线的每一个模块都能回溯到其中一条需求。

01tokio · axum · sqlx

云后端是最大的需求方向

Rust 岗位集中在四类：云后端服务、交易与量化系统、区块链、基础设施与编译器。其中云后端占比最大，JD 里反复出现的是 tokio、axum/actix、sqlx、gRPC 与 Kubernetes——本站的路线就沿着这条主线铺。

022026-07 公开挂牌

薪资锚点写在招聘页上

Sangoma 的加拿大远程 Senior Backend Developer (Rust) 公开区间 120,000–135,000 CAD；美国侧 EngFlow 160,000–220,000 USD、Radar 200,000–300,000 USD。这些是 2026-07 抓到的挂牌数字，不是市场推断。

03行业趋势

内存安全正在推动迁移

内存安全缺陷长期占据 C/C++ 代码库严重漏洞的主要部分，监管与大厂都在推动关键组件用内存安全语言重写。这类岗位要的不是“会写语法”，而是能讲清所有权与并发模型的人。

04面试主战场

门槛在心智模型，不在语法

面试真正深挖的是所有权取舍、生命周期标注、静态与动态分发、Send + Sync、async 的阻塞与取消陷阱、unsafe 的边界。这些正是本站练习与面试题库的重心。

Method / 怎么练

学习方式

小题在浏览器里跑，大项目在你自己的终端里跑，验收标准写在清单上。不背语法，只留下能带走的工程习惯。

浏览器内真编译

写完就判，报错就是 rustc 报错

每道练习直接提交到 Rust Playground 编译运行，返回真实的编译器诊断。三种判题模式：比对标准输出、要求通过编译、跑隐藏测试。

本地 cargo 实战

四个能放进简历的小项目

mini-grep、带持久化的 todo CLI、tokio 并发抓取器、axum + sqlx + WebSocket 完整后端。项目在你自己的机器上用 cargo 跑，和上班时一样。

验收清单

完成的标准是写死的

每个项目配一份可勾选的验收清单，含可复制的测试命令。练习与清单共用同一套进度，登录后云端同步，换设备继续。
